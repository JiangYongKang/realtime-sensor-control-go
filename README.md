# realtime-sensor-control-go

本地可运行的实时传感器采样与安全控制通道。使用模拟设备与可手工推进的时钟
产生采样数据和总线报文，使调度、协议兼容与故障降级在真实工程环境下得到
一致且可解释的结论。

## 结构

| 包          | 职责                                       |
|-------------|--------------------------------------------|
| `clock`     | 可手工推进的确定时钟（并发安全）           |
| `schedule`  | 多周期、多优先级的确定性采样调度           |
| `protocol`  | 带版本的总线报文编解码与校验               |
| `safety`    | 看门狗与安全降级状态机                     |
| `control`   | 组合以上组件的并发安全控制器               |
| `cmd/demo`  | 本地端到端演示（正常/故障/恢复/超时）      |

## 调度与时间语义（schedule）

- 时间以纳秒计，由 `clock.ManualClock` 显式推进，完全确定、可复现。
- 每路任务的第 n 个时隙计划时刻为 `base + n*Period`（base 为注册时刻），
  按绝对倍数计算，**长时间运行不产生累积漂移**。
- 截止时刻即计划时刻本身：未能在计划时刻处理即为时序异常。
- 同一时刻到期的多路任务按 `(scheduledAt, Priority, ID)` 排序派发，
  顺序完全确定。
- 每个时隙都有确定去向，不会被静默丢弃或提前消费：
  - 准时：在计划时刻执行；
  - `MissMarkLate`：最新逾期时隙仍执行并标记 `Late`，中间时隙记为 `Missed`；
  - `MissSkip`：逾期时隙全部记为 `Missed`，等待下一周期。
- 执行回调的错误记录在 `Outcome.Err`，不影响其他时隙的派发。

## 协议版本兼容规则（protocol）

帧格式（大端序）：

```
magic(2) | version(1) | kind(1) | hdrLen(2) | seq(4) | payloadLen(2) | payload | crc32(4)
```

- `hdrLen` 指示完整头部长度：高版本可在基础头之后追加扩展字段，
  解码器按 `hdrLen` 跳过未知字段，**新增字段不影响既有处理**。
- 版本号在 `[MinSupportedVersion, MaxSupportedVersion]` 内被接受；
  更高版本以 `ErrUnsupportedVersion` 明确拒绝。
- 失败原因可区分（均可用 `errors.Is` 判断）：
  `ErrTruncated`（截断）、`ErrChecksum`（校验失败）、`ErrInvalidMagic`、
  `ErrInvalidField`、`ErrUnsupportedVersion`、`ErrPayloadTooLarge`。
- 解码器**无状态**：一次失败不会污染后续报文，调用方按返回的消耗
  字节数推进流即可继续解码后续帧。

## 安全降级行为（safety + control）

- 每路通道一个看门狗：连续错过/异常达到 `maxMisses` 即进入安全状态。
  因采样周期已知，检测时限上界为 `maxMisses * Period`，满足约定时限。
- 错过截止时间、设备错误、报文解码失败、序号回退（`ErrStaleSeq`）
  均计为一次异常；任一通道进入安全态则全局状态为 `SAFE`。
- 安全态下通道快照标记 `Stale=true`，故障期间的数据不可沿用。
- 恢复：一次正常事件即回到正常态，并**重置全部故障期计数**——
  恢复后需重新累计满阈值才会再次触发。
- 看门狗记账严格按调度结果的时间顺序进行（Miss 与 Feed 交错），
  不会出现“先成功后补记旧错过”的顺序错乱。
- 并发：控制器全部共享状态由单一互斥锁保护，快照为一致性拷贝，
  采样、控制与状态读取并发执行不会出现半更新或数据竞争；
  时钟与看门狗自身亦可并发调用。

## 本地验证

```sh
# 全部测试（含竞态检测）
go test ./... -count=1 -race

# 静态检查
go vet ./...

# 运行端到端演示（正常采样 -> 报文损坏 -> 安全降级 -> 恢复 -> 超时错过）
go run ./cmd/demo
```

测试覆盖：错过截止时间（`MissSkip`/`MissMarkLate`）、长时间运行无漂移、
报文截断/损坏/版本兼容/扩展头前向兼容、故障触发与恢复、序号回退、
快照隔离，以及 `-race` 下的并发采样与状态读取。所有用例基于手工时钟，
结果完全可复现。
